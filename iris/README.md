# IRIS

IRIS is a domain-agnostic kernel. It consumes external organs and components
through explicit contracts. IRIS initiates SOL and computes their fractal
representations.

For ARKÉ, IRIS performs the matching between researchers or with people
already present in the user's phone contacts. The associated ingress and egress
cross a SOL, which owns canonical I/O conversion rather than matching.

IRIS must not absorb business logic or a concrete organ implementation.
