# Sources historiques incomplètes

Ces trois scripts sont conservés pour audit historique. Ils importent
`trajectory.extract_blocks`, mais le fichier source `trajectory.py` n'a pas
été fourni dans le corpus individuellement vérifiable.

Conséquences :

- leur syntaxe Python peut être contrôlée ;
- ils ne font pas partie du chemin exécutable validé ;
- leurs résultats top-k et de dissipation ne sont pas annoncés comme reproduits ;
- les fichiers `.pyc` visibles dans les captures ne sont pas publiés : du
  bytecode ne remplace pas une source auditable.

Ces limites n'ont aucun rapport avec le statut de la conjecture : Collatz Scan
ne la prouve pas.
