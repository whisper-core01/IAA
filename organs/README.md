# Organs

Organs are replaceable capabilities admitted through explicit kernel contracts.
An organ owns one responsibility and cannot redefine kernel semantics.

The initial candidate map inherited from the research vocabulary includes DOME,
DAEMON, MEMBRANE, LEMONADE, BAL, MCE, VAULT, RETICULUM-BRIDGE, ROTORMACHINE,
SANDBOX, WASM-HOST, STORAGE, SCHEDULER, and OBSERVABILITY. WASM-HOST and SANDBOX
belong to the canonical deployment boundary: IRIS, ARGOS, and AORATOS each use
a separate environment. Their names and required topology do not imply that an
implementation or security property already exists in this repository.
