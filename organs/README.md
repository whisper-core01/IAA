# Organs

Organs are replaceable capabilities admitted through explicit kernel contracts.
An organ owns one responsibility and cannot redefine kernel semantics.

The initial candidate map inherited from the research vocabulary includes DOME,
DAEMON, MEMBRANE, LEMONADE, BAL, MCE, VAULT, RETICULUM-BRIDGE, ROTORMACHINE,
SANDBOX, WASM-HOST, STORAGE, SCHEDULER, and OBSERVABILITY. Names do not imply
that implementations or security properties already exist.
