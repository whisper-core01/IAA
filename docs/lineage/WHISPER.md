# WHISPER lineage

## Relationship

IAA succeeds the architectural research recorded in the public
[`whisper-core01/whisper`](https://github.com/whisper-core01/whisper) repository
and related WHISPER Remote Nerve experiments.

The relationship is intentionally explicit:

- Whisper is deprecated and no longer maintained; its historical content remains publicly available;
- IAA is a distinct repository and architecture baseline;
- concepts may be re-admitted only through IAA contracts and evidence gates;
- no implementation, test result, security property, or compatibility claim is
  inherited merely because it existed in a WHISPER document;
- contradictory historical wording is not normative for IAA.

## Why a new repository

The historical Whisper README combines vision, architecture, implementation,
and strong security assertions. IAA separates those layers so that doctrine,
contracts, implementation, and evidence can evolve without being confused.

## Historical status

WHISPER should be read as project provenance. IAA documentation is authoritative
for IAA. Where the two disagree, IAA makes no claim about Whisper and follows
its own current, versioned documents.
